## Overview

가상의 카드사 콜센터를 배경으로, 고객 통화를 실시간 STT로 전사해 인입 의도를 분류하고 관련 정책·FAQ 문서를 상담사 화면에 즉시 제시하는 Agent PoC입니다. 통화 종료 후에는 대화 내용을 바탕으로 상담 후처리(유형·요약·처리 내용) 초안을 자동 작성해, 상담사의 반복 업무를 줄이고 응대 품질을 높이는 것을 목표로 했습니다.

## Problem

- 상담사는 통화 중 고객 문의를 파악하면서 동시에 내부 시스템에서 관련 정책·약관을 직접 찾아야 해, 응대 속도가 느려집니다.
- 상담사별로 문서 접근 숙련도가 달라 동일 문의에도 답변 품질 편차가 생깁니다.
- 통화 종료 후 후처리(유형 분류·요약·처리 기록 입력)는 반복적이고 시간이 많이 걸립니다.

## Role & Scope

- STT 연동 시나리오 설계, 의도 분류·RAG 파이프라인 구성, 후처리 자동 생성 흐름, 데모 UI 전 과정을 담당했습니다.
- PoC 범위: 실시간 STT 전사, 고객 인입 의도 분류, 근거 문서 검색·표시, 통화 후 후처리 초안 자동 생성.
- 실제 CTI·콜센터 인프라 연동, 전사 배포, 개인정보 처리 정책은 범위에서 제외했습니다.

## Approach

- 실시간 STT 스트림을 수신해 고객 발화를 청크 단위로 전사하고, 의도(결제·한도·분실·해지 등)를 분류합니다.
- 분류된 의도와 키워드로 내부 정책·FAQ 문서를 하이브리드 검색해, 상담사 화면에 관련 근거 스니펫을 실시간으로 노출합니다.
- 통화 종료 시점에 전체 대화 전사본을 요약해 상담 유형·처리 내용·특이사항을 구조화한 후처리 초안을 자동 생성합니다.

## Tech Stack

- 실시간 STT(Mock 스트림) · LLM Agent · RAG(벡터 DB + 메타 필터)
- Python · FastAPI — 스트림 수신, 의도 분류, 문서 검색
- React — 상담사 대시보드(실시간 전사·근거 문서·후처리 입력 UI, 데모)

## Outcome

- 카드사 주요 문의 시나리오(한도 조회·분실 신고·결제 이의제기)로 엔드투엔드 데모를 완료했습니다.
- 실시간 문서 제시로 상담사가 시스템을 별도 검색하지 않아도 되는 흐름을 검증했습니다.
- 후처리 초안 자동 생성으로 입력 시간을 단축할 수 있음을 내부 검증했습니다.
- 후속: 실제 CTI 연동, 개인정보 마스킹, 상담사 피드백 기반 문서 랭킹 개선.
