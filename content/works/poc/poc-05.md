## Overview

실시간 경기 이벤트(타석·득점·교체 등)와 선수·팀 통계를 입력하면, 중계 톤에 맞는 해설 멘트 초안을 생성하는 PoC입니다. 상황별 템플릿과 통계 인용을 조합해 자연스러운 실황·분석 멘트를 검증했습니다.

## Problem

- 실시간 경기에서는 해설 멘트가 빠르게 이어져, 상황·통계를 동시에 반영하기 어렵습니다.
- 선수·팀 스토리를 일관된 톤으로 전달하려면 준비 데이터가 많습니다.
- 동일 상황도 톤(흥분·분석·담담)에 따라 표현이 달라져야 합니다.

## Role & Scope

- 해설 시나리오·톤 가이드, 이벤트→멘트 파이프라인, 데모 UI를 담당했습니다.
- PoC 범위: 이벤트 기반 멘트 생성, 통계 인용, 톤 프리셋.
- 실제 방송 송출·음성 TTS·저작권 중계 데이터 연동은 범위에서 제외했습니다.

## Approach

- 경기 이벤트 JSON을 받아 상황 유형별 프롬프트를 선택합니다.
- 선수·팀 시즌 스탯을 컨텍스트로 주입해 근거 있는 멘트를 생성합니다.
- 톤(실황/분석/하이라이트) 프리셋으로 출력 스타일을 제어합니다.

## Tech Stack

- LLM API · 상황별 프롬프트
- Python · FastAPI · 이벤트 스트림(Mock)
- React — 타임라인·멘트 출력 UI(데모)

## Outcome

- 이닝·득점 등 시나리오 데모를 완료했습니다.
- 통계 인용·톤 차별화를 내부 검증했습니다.
- 후속: 실시간 피드 연동, TTS, 다국어 중계.
