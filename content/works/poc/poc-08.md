## Overview

원작 웹소설·시나리오 텍스트를 입력하면, 타겟 언어·문화권·연령 등급에 맞춰 서사 구조와 문체를 유지한 채 리라이팅 초안을 생성하는 PoC입니다. 직역이 아닌 현지화 품질(감정선·관용표현·호칭)을 검증하는 데 초점을 두었습니다.

## Problem

- 해외 진출 시 직역 위주 번역은 감정선·문화 맥락이 어색해져 독자 이탈로 이어지기 쉽습니다.
- 원작 문체·캐릭터 톤을 유지하면서 현지 규제·표현 습관을 반영하려면 작가·번역가의 반복 수정이 필요합니다.
- 대량 회차를 처리할 때 품질 기준을 통일하기 어렵습니다.

## Role & Scope

- 현지화 가이드 정의, 프롬프트·검수 체크리스트 설계, 샘플 회차 데모 UI까지 PoC 전 과정을 담당했습니다.
- PoC 범위: 텍스트 입력·회차 단위 리라이팅, 톤·호칭·관용어 가이드 반영.
- 전체 자동 출판·저작권 검증·실시간 연재 연동은 범위에서 제외했습니다.

## Approach

- 원문에서 인물·사건·감정 키워드를 추출해, 타겟 문화권에 맞는 표현 후보를 생성합니다.
- 문체·시점·호칭 규칙을 시스템 프롬프트로 고정해 회차 간 일관성을 유지합니다.
- 생성문과 원문을 나란히 보여 주고, 수정 포인트(직역투·뉘앙스)를 코멘트로 제안합니다.

## Tech Stack

- LLM API · 프롬프트 체인(분석 / 리라이팅 / 품질 코멘트)
- Python · FastAPI
- React — 원문·결과 비교 UI(데모)

## Outcome

- 다수 장르·언어 조합 샘플로 엔드투엔드 데모를 완료했습니다.
- 문체 유지·관용어 현지화 개선 포인트를 체크리스트로 정리했습니다.
- 후속: 용어집·캐릭터 바이블 연동, 인간 검수 워크플로, A/B 품질 평가.
