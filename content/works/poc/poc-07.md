## Overview

외국인 관광객의 선호·체류 시간·이동 수단·주변 POI 정보를 입력하면, 맞춤형 관광지·동선·코스를 추천하는 RAG 기반 PoC입니다. 실시간 검색과 지도 맥락을 결합해 설명 가능한 추천 사유를 함께 제공합니다.

## Problem

- 관광객마다 선호·동선·체류 패턴이 달라 범용 Top-N 추천만으로는 만족도가 낮습니다.
- 분산된 리뷰·운영 정보·교통 데이터를 한 흐름에서 설명하기 어렵습니다.
- 추천 이유 없이 결과만 제시하면 신뢰도가 떨어집니다.

## Role & Scope

- 추천 시나리오·데이터 소스 정의, RAG 파이프라인·데모 UI 구성을 담당했습니다.
- PoC 범위: 질의 기반 장소 추천, 코스 초안, 추천 근거 문장 생성.
- 실시간 예약·결제·공공 API 상용 연동은 범위에서 제외했습니다.

## Approach

- 사용자 조건을 구조화해 벡터·메타데이터 하이브리드 검색으로 후보를 좁힙니다.
- 동선·거리·카테고리 제약으로 코스를 재정렬합니다.
- 추천 결과마다 근거 스니펫·요약 설명을 붙여 RAG 응답을 구성합니다.

## Tech Stack

- LLM · RAG(벡터 DB + 메타 필터)
- Python · FastAPI
- React — 지도·리스트·설명 패널 UI(데모)

## Outcome

- 시나리오별 추천·코스 데모를 완료했습니다.
- 근거 문장 포함 응답으로 설명 가능성을 검증했습니다.
- 후속: 실시간 혼잡도·다국어 UI·제휴 POI API.
