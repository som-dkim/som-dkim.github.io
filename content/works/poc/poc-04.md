## Overview

가상 스트리머 페르소나(말투·가치관·금지 표현)를 정의하고, 연애 상담형 라이브 대화 시나리오에서 일관된 응답을 생성하는 PoC입니다. 페르소나 드리프트를 줄이고, 시청자 질문 유형별 응답 가이드를 검증했습니다.

## Problem

- 캐릭터형 콘텐츠는 말투·세계관이 흔들리면 몰입도가 급격히 떨어집니다.
- 연애 상담은 민감 표현·가이드라인 관리가 필요합니다.
- 긴 대화에서 페르소나가 섞이거나 반복되기 쉽습니다.

## Role & Scope

- 페르소나 카드·금지어·시나리오 설계, 대화 파이프라인·데모 UI를 담당했습니다.
- PoC 범위: 텍스트 상담 대화, 페르소나 고정, 시나리오 분기.
- 실제 라이브 플랫폼·영상 아바타·결제 연동은 범위에서 제외했습니다.

## Approach

- 페르소나·말투·금지 표현을 시스템 레이어로 고정합니다.
- 질문 유형(고민·이별·썸 등)별 응답 템플릿을 분기합니다.
- 최근 턴 요약을 유지해 장문 대화에서도 일관성을 보완합니다.

## Tech Stack

- LLM · 페르소나 프롬프트 · 턴 요약 메모리
- Python · FastAPI
- React — 채팅·페르소나 설정 UI(데모)

## Outcome

- 대표 상담 시나리오 데모를 완료했습니다.
- 페르소나 유지·금지어 회피 기준을 정리했습니다.
- 후속: 음성·아바타, 모더레이션 API, 시청자 통계 연동.
