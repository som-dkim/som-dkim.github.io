## Overview

ERP 데이터에서 이상 징후를 탐지하기 위해 DBSCAN·회귀·SOM·계층 클러스터링 등 다양한 분석·ML 기법을 적용하고, 전 그룹사 자동화 플랫폼에 탑재 가능한 모형을 개발한 프로젝트입니다.

## Context

- 내부 감사·리스크 관리를 위한 ERP 데이터 기반 이상 탐지 필요
- 단일 기법이 아닌 다양한 패턴·이상 유형에 대응할 모델 탐색 필요
- 그룹사 공통 플랫폼에 적용 가능한 표준 모형 요구

## Role

- ERP 데이터 수집·정제·탐색적 분석
- DBSCAN·회귀·SOM·계층 클러스터링 기반 이상 탐지 모델 개발·비교
- 플랫폼 탑재용 모형·문서·검증 산출물 작성

## Data & Analysis

- ERP 거래·계정·조직 데이터 피처 엔지니어링
- 이상치·군집·차원축소 기법 조합 실험
- 모델 성능·해석 가능성·운영 적합성 평가

## Deliverables

- 이상 탐지 모델 및 실험·비교 리포트
- 플랫폼 탑재용 API·배치 스펙·운영 가이드
- 감사·리스크 팀 검토용 시각화·케이스 스터디

## Impact

- 전 그룹사 자동화 플랫폼에 이상 탐지 모형 탑재
- 내부 감사·리스크 모니터링 자동화 기반 마련
