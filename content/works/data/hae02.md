## Overview

자동차 행동 데이터를 활용해 GMM·DBSCAN·K-means 등 클러스터링 기법으로 고객군을 분류하고 마켓 타겟층을 수립했으며, 프로젝트 관리·산출물 작성·분석 코드 최적화를 담당한 프로젝트입니다.

## Context

- 행동 데이터 기반 고객 세분화·타겟 마케팅 니즈 증가
- 여러 클러스터링 기법 비교·검증이 필요
- 분석 재현성·운영 가능한 코드·명확한 산출물이 요구됨

## Role

- 행동 유형 세분화·타겟 분류 분석 수행
- GMM·DBSCAN·K-means 등 모델 실험·비교·선정
- 프로젝트 일정·품질 관리, 산출물 작성, 코드 최적화

## Data & Analysis

- 자동차 행동 로그·속성 데이터 전처리·피처 설계
- 클러스터링 모델 학습·평가·해석
- 세그먼트별 프로파일링 및 마케팅 타겟 제안

## Deliverables

- 세그먼테이션 분석 보고서 및 세그먼트 정의서
- Python 분석 코드·재현 가능한 파이프라인
- 경영·마케팅 공유용 시각화·요약 자료

## Impact

- 데이터 기반 고객 타겟층 수립으로 마케팅·기획 의사결정 지원
